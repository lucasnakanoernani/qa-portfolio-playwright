  • Playwright
  • TypeScript
Ver no GitHub ↗
Sobre o teste +

Objetivo

Automatizar o preenchimento do cadastro e o envio de um arquivo em um formulário de demonstração com campos de CPF e CEP.

Implementação

Dados pessoais obtidos por API alimentam o cadastro. As ações do formulário ficam organizadas em Page Objects, incluindo o envio do documento de teste.

A mensagem “Obrigado!” precisa estar visível após o envio. Essa verificação confirma a resposta da interface; não verifica a persistência dos dados no banco de dados.

03Practice Software Testing

Pesquisa e validação de produto

Pesquisa por Protective Gloves com seletores específicos para distinguir o nome do produto do termo de busca.

  • Playwright
  • TypeScript
Ver no GitHub ↗
Sobre o teste +

Problema encontrado

O mesmo nome aparecia no termo pesquisado e no produto. Um localizador baseado apenas no texto encontrava mais de um elemento.

Decisão

Selecionar separadamente o termo pesquisado e o nome do produto, aplicando um filtro específico para o resultado esperado.

O que é validado

O termo de pesquisa corresponde ao valor esperado e o produto está visível na página de resultados.
